# PyTorch 推理基线

## 目的

在开始 ONNX、TensorRT 和 CUDA 优化前，建立一条可信的 PyTorch 参考结果。后续所有加速结果都必须与它比较正确性和性能。

## 预期结果

- 模型能够在 GPU 上稳定运行。
- 明确记录模型、输入 shape、batch、dtype 和环境。
- 区分预热与正式测量。
- GPU 计时包含正确同步。
- 输出 P50、P95、P99、吞吐量和峰值显存。
- 重复运行时结果波动可以解释。
