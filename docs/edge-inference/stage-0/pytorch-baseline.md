# PyTorch 推理基线

## 为什么先做 PyTorch 基线

先用 PyTorch 跑出一条可信的参考结果。后面做 ONNX、TensorRT 和 CUDA 优化时，速度和精度都要拿它来对比

## 这一轮要拿到什么

- 模型能在 GPU 上稳定运行
- 写清模型、输入 shape、batch、dtype 和环境
- 分开预热和正式测量
- GPU 计时包含正确的同步
- 输出 P50、P95、P99、吞吐量和峰值显存
- 重复运行时，能解释结果为什么会有波动
