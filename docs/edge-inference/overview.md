## 记录原则

每项实践至少保留以下内容：

1. 这次实践想解决什么问题
2. 实际执行的命令和当时的环境
3. 原始输出或结果文件放在哪里
4. 怎么理解结果，哪些地方和预想不一样
5. 遇到了什么问题，怎么一步步查出来的
6. 下一步准备做什么

成功的结果要记，失败的命令、错误的猜测和排查过程也要留着，这些往往更有用
