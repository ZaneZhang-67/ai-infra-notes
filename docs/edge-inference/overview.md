## 记录原则

每项实践至少保留以下内容：

1. 目的与预期结果。
2. 实际执行的命令和关键环境信息。
3. 未加工的原始结果或结果文件位置。
4. 对结果的解释，以及与预期不一致的地方。
5. 遇到的问题、排查证据和最终结论。
6. 下一步实验。

不只记录成功结果。失败命令、错误假设和定位过程同样属于实践成果。
